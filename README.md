# CChibiVim
Vim-like editor for ComputerCraft (CC:Tweaked) Minecraft mod. Tested on CraftOS. For using just run cchibivim.lua file
## Usage
For motion it using vimmotions h/j/k/l and others.
To enter a normal mode u should press j then k (For now, this works every time you press these keys.)
